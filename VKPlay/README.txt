ДОСТИЖЕНИЯ VK PLAY — ФАЙЛЫ ДЛЯ СБОРКИ

Положите сюда файл steam_api64.dll от VK Play. При сборке под Windows
(File → Build) он сам скопируется рядом с Astropolity.exe.

Где взять:
1. Скачайте архив VK Play: https://static.gc.vkplay.ru/guptools/steam_api_dlls.7z
   (ссылка из документации: documentation.vkplay.ru → Premium игры → Достижения).
2. Откройте папку 10.87.46.89\Release (самая новая версия).
   Старые версии не подойдут: в них нет нужных функций.
3. Скопируйте оттуда Steam_API64.dll в эту папку и переименуйте в steam_api64.dll.

Для теста можно взять версию из папки Debug: она пишет журнал FUME.log
рядом с собой — его просит поддержка VK Play, если что-то не работает.
В релиз — только Release.

Если VK Play выдаст Steam AppID для эмуляции (кабинет → «Системные свойства»
→ «Режим эмуляции Steam»), запишите это число в файл steam_appid.txt
в этой же папке — он тоже скопируется в сборку.

Без этих файлов игра работает как обычно: достижения хранятся на компьютере
и уйдут в VK Play, когда библиотека появится.
