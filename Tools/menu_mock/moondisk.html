A · ПОЛНАЯ ЛУНА

Настоящая луна из текстуры проекта во весь диск, фаза — тенью по шару. Под цифрами — мягкая тёмная подложка, чтобы дата читалась.

B · ЛУНА НА ОРБИТЕ

Маленькая луна идёт по кольцу месяца, как спутник: где она — такая часть месяца прошла, её фаза меняется по пути. Циферблат чистый.

C · ГОЛО-ТЕРМИНАТОР

Циферблат сам — луна: поверхность едва видна в цвете HUD, освещённый край — яркий бирюзовый серп со свечением вдоль границы света.
