# Локализация (русский → английский)

Код пишется по-русски, как раньше. Видимые игроку строки идут через `Loc.T("…")` / `Loc.F("… {0}", x)`
(`Assets/Scripts/Core/Loc.cs`); перевод — `Assets/Resources/Localization/en.txt`, строки `русский<TAB>english`
(`\n`, `\t`, `\\` экранированы). Нет перевода — в английской версии показывается русский текст.

## Новые строки
1. Обернуть новые русские строки автоматически (нужны `tree_sitter` и `tree_sitter_c_sharp` для Python):
   `python3 loc_tool.py apply ../../Assets/Scripts`
   Атрибуты, const, значения по умолчанию, `case`, сравнения, `Contains/StartsWith…`, ключи индексаторов
   и `Debug.Log` инструмент не трогает.
2. Список ключей: `python3 loc_tool.py extract ../../Assets/Scripts keys.json` — переведите те, которых нет в en.txt,
   по правилам GLOSSARY.md (плейсхолдеры `{0}`, теги `<color>`, пробелы по краям — без изменений)
   и допишите строки в en.txt.
3. Проверка партии перевода: `python3 validate.py in.json out.json`.

Язык выбирается при запуске (Настройки → Интерфейс → «Язык · Language», по умолчанию — язык системы)
и меняется только после перезапуска игры.
