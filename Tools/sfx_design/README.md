# Звуки стратегического слоя

`build.py` синтезирует звуки интерфейса, уведомлений, времени, карты и флотов, стройки и науки,
космического боя и стингеры в `Assets/Resources/Audio/Sfx/<Имя>_N.ogg` (имя = значение `Sfx`;
`SFXManager` подхватывает записи сам и выбирает дубль случайно, без повторов подряд). Карточный бой
(`Tools/card_audio`) и `Construction_*` не трогаются.

```
python3 Tools/sfx_design/build.py                  # все звуки
python3 Tools/sfx_design/build.py UiClick FtlJump  # выборочно
python3 Tools/sfx_design/build.py --preview DIR    # только wav в DIR, игра не меняется
```

Нужны `numpy`, `scipy` и `ffmpeg` с libvorbis.

- `dsp.py` — движок: биквады и движущиеся фильтры, полиBLEP-осцилляторы, шумы, свёрточная
  реверберация с синтетическими импульсами (booth, room, plate, hall, space; частотно-зависимое
  затухание и ранние отражения), насыщение и «плёнка», компрессор, ограничитель по истинному пику,
  громкость по BS.1770.
- `sounds.py` — словарь слоёв (щелчок, корпус, стекло и металл на неармонических модах, сервопривод,
  поток воздуха, суббас, гул, телеметрия, треск, подложка, «браам», удар, набег, взрыв, рация)
  и рецепт каждого звука. Тональные слои — неармонические моды материалов, а не синусы с глиссандо.
- Громкость: `DESIGN` в `build.py` — задуманная громкость каждого звука «в игре» с учётом
  `SfxDef.Volume`; общий уровень привязан к среднему прежних звуков (`reference_lufs.json`),
  чтобы не сбить баланс с музыкой. Звуки мира сужены по стерео (их панорамирует игра).
