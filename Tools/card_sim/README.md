# Симулятор карточного боя (вне Unity)

Правила боя (`Assets/Scripts/Cards/Battle`, `Assets/Scripts/Cards/Data`) — чистый C#, их можно гонять
тысячами автобоёв обычным компилятором Mono, без Unity. `Stub.cs` подменяет `Loc` из игры.

```
cd Tools/card_sim
mcs -target:library -out:rules.dll Stub.cs ../../Assets/Scripts/Cards/Battle/*.cs ../../Assets/Scripts/Cards/Data/*.cs
mcs -out:sim.exe -r:rules.dll Sim.cs
LANG=C.UTF-8 mono sim.exe 3000 16      # боёв, карт в колоде десанта
```

Печатает: долю побед атаки, прорывов и отступлений, среднюю длину боя и распределение по ходам,
карт за ход, неистраченные очки, остаток колод и рук, выстрелы, гибели и смены контроля секторов.
Расстановка — как у тестового боя (F10): случайные колоды, укрепления 0–3, ИИ против ИИ.

## Штурм как в игре (`Assault.cs`)

```
mcs -out:assault.exe -r:rules.dll Assault.cs
LANG=C.UTF-8 mono assault.exe table 300       # доля побед атаки: укрепления 0–3 × десант 4–20 карт
LANG=C.UTF-8 mono assault.exe factions 6000   # каждая фракция в атаке и обороне
EXCL=X4 LANG=C.UTF-8 mono assault.exe factions 4000   # то же без карты X4 — её вклад
```

Бой собирается как `AssaultLink.Build`: десант — состав по доктрине (пехота, техника 25%, приказы 15%, фракционные
карты), оборона — резерв защитника по местам колонии (3 + жители/4 + 2 за уровень укреплений), ополчение от жителей,
щит Штаба и турель на каждый уровень укреплений.

Ориентиры баланса (середина партии, десант 16 карт): колония без укреплений — около 85–95% побед атаки,
укреплённая база — 60–80%, крепость — 55–65%, цитадель — 35–45%. Фракции в атаке — в пределах 70–77%.
