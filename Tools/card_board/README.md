# Стол карточного боя

`board.html` — SVG-рисунок тактического стола десанта: бронированная рама (швы, заклёпки, угловые плиты с полосой
«опасность» и лампами, выступы под портреты, светящаяся кромка поля), посадочные площадки под ряды карт
(враг — красная подсветка к линии фронта, вы — бирюзовая) и линия фронта посередине.

```
node Tools/card_board/render.js Assets/Resources/UI/CardBattle 1.25
```

Даёт `board_frame.png`, `board_pad_enemy.png`, `board_pad_mine.png`, `board_midline.png`. Геометрия совпадает с
`BattleScreen`: стол 1480×600, рама — с запасом 60 px со всех сторон, окно поля на 8 px внутрь края стола.
Нет этих картинок — экран боя рисует прежний стеклянный стол с ячейками.
