# Поле карточного боя

`board.html` — поле на весь экран в стиле голографического тактического стола: тёмное дымчатое стекло и неоновые
контуры (без металла). Интерфейс встроен в поле, а не висит панелями вокруг.

```
node Tools/card_board/render.js Assets/Resources/UI/CardBattle 1
```

| Файл | Что это | Как рисуется в игре |
|---|---|---|
| `board_screen.png` (1920×1080) | стекло: полосы под руки, палубы под ряды (враг — красная подсветка к фронту, вы — бирюзовая), полоса фронта, капсула счёта, диск кнопки хода, угловые плиты | обычная прозрачность |
| `board_lines.png` (1920×1080) | только светящиеся контуры: уголки палуб, кромки цвета стороны, швы секторов, линия фронта с узлами, гнёзда счёта и кнопки хода, кромки плит | шейдер `Holo` (`Assets/Resources/Shaders/UIHolo.shader`): перелив по радуге и бегущий блик |
| `holo_ring_a.png`, `holo_ring_b.png` (512) | голографические кольца: риски и дуги / сегменты и точки | `Holo` + вращение (`HoloSpin`): за портретами лидеров, вокруг гнёзд счёта и кнопки хода |
| `holo_rays.png` (512) | мягкий нимб с лучами | `Holo` + медленное вращение за портретом лидера |

Ещё живые эффекты в коде (`Assets/Scripts/Cards/UI/HoloFx.cs`): искры цвета фракции поднимаются из-за портрета
лидера (`HoloMotes`), по линии фронта пробегает импульс энергии (`HoloRunner`), свечение за портретами и гнёздами
счёта «дышит».

Геометрия совпадает с константами `BattleScreen`: центр (960, 540), ряды на y ±214, секторы через 470 px, гнездо счёта
x −845 (гнёзда на y ±78), гнездо кнопки хода x +835 (паз r 104), плашки игроков (−720, ±476).
Нет `board_screen.png` — экран боя рисует прежний стеклянный стол с ячейками и панелями по бокам.
