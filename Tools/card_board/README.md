# Стол карточного боя

`board.html` → `#screen` — SVG-подложка всего экрана боя 1920×1080 (как в больших карточных играх: поле на весь экран,
интерфейс встроен в стол, а не висит панелями вокруг):

- тёмные полосы сверху и снизу — под руки (рука врага рубашками у верхнего края, ваша — веером из-за нижнего);
- две палубы под ряды карт (y ±214, ширина 1440) со швами секторов на x ±235: у врага красная подсветка к фронту, у вас — бирюзовая;
- линия фронта посередине с ромбами-узлами между секторами (на ней лежат плашки секторов);
- слева на линии — гнездо счёта (капсула с двумя гнёздами на y ±78: враг сверху, вы снизу);
- справа на линии — гнездо кнопки хода (кольца r 132/104/86: по пазу r 104 сверху деления ходов, снизу кристаллы очков приказов);
- угловые плиты: слева сверху и снизу — под плашки игроков (портрет и имя), справа сверху — под кнопки скорости / автобоя / отступления.

```
node Tools/card_board/render.js Assets/Resources/UI/CardBattle 1
```

Даёт `board_screen.png`. Геометрия совпадает с константами `BattleScreen` (Lane 470, RowOff 214, LX −845, RX 835).
Нет этой картинки — экран боя рисует прежний стеклянный стол с ячейками и панелями по бокам.
Остальные рисунки в `board.html` (`#frame`, `#pad_*`, `#midline`) — первая версия стола в раме, сейчас не используются.
