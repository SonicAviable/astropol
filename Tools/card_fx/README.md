# Эффекты карточного боя (fx2_*)

`gen_fx.py` рисует кодом флипбуки эффектов в `Assets/Resources/UI/CardBattle/fx2_<имя>.png` — без чужих ассетов.
Белый RGB, яркость — в альфе. В игре их рисует шейдер `Astropolity/UI/FxRamp` (`Resources/Shaders/UIFxRamp.shader`):
яркое ядро уходит в белый, края — в цвет оттенка, поэтому одна текстура годится для любого цвета.
Вызов из кода: `UIFx.Play(UIFx.Fx2.<Эффект>, позиция, цвет, размер, длительность, …)`.

```
python3 Tools/card_fx/gen_fx.py Assets/Resources/UI/CardBattle [папка_превью] [имена,через,запятую]
```

Нужен `numpy` и `Pillow`. С папкой превью рядом появится `fx_preview.jpg` — кадры каждого эффекта, раскрашенные как в игре.

| Эффект | Кадры | Где в бою |
|---|---|---|
| impact — звезда удара с лучами, штрихами и кольцом | 4×4 | попадания, урон без стрелка, взрывы |
| slash — рассекающая дуга (кадр 2:1) | 4×4 | клинок командира, снайперы |
| shock — ударная волна | 4×4 | раскрытие, гибель, взрывы, розыгрыш крупным планом |
| burst — веер лучей с бликами | 6×6 | легендарные и герои, захват сектора, «ВАШ ХОД», гибель техники |
| circle — тактический рунный круг | 6×6 | приказы |
| pillar — столб света с основанием (кадр 1:2) | 4×4 | усиление, лечение |
| lightning — ветвистые молнии | 4×4 | энергоразряды, падение щита Штаба |
| sparkle — блёстки-звёздочки | 4×4 | усиление, лечение |
| hexshield — волна по сотам щита | 4×4 | укрытие, щит Штаба |
