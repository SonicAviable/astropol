# Правила экономии токенов

- Отвечай кратко, по-русски, без вступлений, пересказа задачи и итоговых резюме.
- Не перечитывай файлы, уже прочитанные в сессии; читай только нужные строки (offset/limit, grep -n).
- Ищи через Grep/Glob с узкими путями, а не читай целые папки. Не используй субагентов без прямой просьбы.
- Код — только `Assets/Scripts/` и `Assets/Editor/`. Не открывай `.meta`, `.unity`, `.prefab`, `.asset`, `.mat`, звук, модели и сторонние ассеты (`SpaceSkies Free`, `ParallelCascades`, `TutorialInfo`).
- Не выводи большие диффы и логи целиком: `| tail -n 30`, `| head`.
- Не запускай сборку/тесты, если не просили.
- Правь точечно (Edit), не переписывай файлы целиком.
