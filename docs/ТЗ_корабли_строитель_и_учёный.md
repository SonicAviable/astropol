# ТЗ: 3D-модели строительного и научного кораблей для 6 империй

Исполнитель: Астра (Blender). Движок: Unity 6, URP. Итого **12 моделей** (6 империй × 2 корабля).
Планка качества: уровень кораблей Stellaris (читаемый силуэт, детальный «ручной» хард-серфейс, запечённые AO и износ, осмысленные узлы и надписи-панели).

Сейчас в игре стоят временные модели: научный — зонд «Марс-3» (один на всех), строительный — набор Star Sparrow, иначе процедурные коробки. Новые модели заменяют их.

## 1. Где и как видны модели

- Основной вид — **карта галактики сверху** (камера далеко, корабль ~20–60 px). Главное требование — **силуэт**: по контуру сразу видно «империя + строитель или учёный».
- Вторичный вид — голограмма в верфи/окне флота и вблизи при приближении камеры (до ~800 px). Здесь нужна полная детализация.
- Корабль подсвечивается цветом владельца (полосы) и жёлтой подсветкой при выборе.

## 3. Роли кораблей

### 3.1 Научное судно
Исследует системы (разведка), в игре стоит на орбите и «сканирует». Хрупкое, без вооружения.
Обязательные узлы: сенсорный комплекс (тарелка/кольцо/решётка/кристалл), лаборатория (обитаемый или аппаратный модуль), мачты антенн, малые зонды/дроны на креплениях.
Силуэт: **широкий** — раскрытые панели, кольцо или тарелка, заметный сенсор.

### 3.2 Строительное судно
Строит форпосты, станции, добычу. В игре в «рабочем» состоянии выпускает лучи/дроны.
Обязательные узлы: грузовой/модульный отсек со строительными блоками, манипуляторы или кран, стыковочные узлы, сварочные/лучевые излучатели.
Силуэт: **вытянутый и тяжёлый** — длинная ферма, контейнеры, «клешни». Крупнее научного.

### 3.3 Конкретика по империям

## 4. Технические требования

### 4.1 Единицы и оси (важно, иначе в Unity будет разворот)
- Blender: 1 unit = 1 м, **Apply All Transforms**, масштаб 1, оси при экспорте: **Forward = +Z, Up = +Y**.
- **Нос корабля — +Z**, верх — +Y, корма — −Z. Начало координат — центр масс, на плоскости симметрии.
- Реальная длина: научное 45–65 м, строительное 70–110 м. В игре масштаб нормируется кодом (~3 ед. по наибольшему размеру), важны только пропорции.
- Научные модели с широкими панелями/кольцами держать в плоскости **XZ** (сверху читается во всю ширину).

### 4.2 Геометрия
- Бюджет LOD0 (трис): научное **8–14 тыс.**, строительное **10–18 тыс.**
- LOD1 ≈ 40 %, LOD2 ≈ 12 % от LOD0 (имена `*_LOD0/1/2`; у LOD2 силуэт сохранён).
- Quad-топология на хард-серфейсе, Bevel + weighted normals, без n-gon на кривых, без нестыкующихся нормалей.
- Подвижные части (кольца, тарелка, манипуляторы) — отдельные объекты с правильным pivot.

### 4.3 Материалы и текстуры
Один набор текстур на корабль, 2048×2048 (LOD0), формат PNG/JPG, **без SSS и прозрачности корпуса** (окна — эмиссия).

| Файл | Содержание |
|---|---|
| `<имя>_albedo.png` | Цвет + запечённая AO, без акцентной полосы (она отдельным слотом) |
| `<имя>_ms.png` | R = Metallic, A = Smoothness (как у существующих моделей в проекте) |
| `<имя>_normal.png` | Normal map, OpenGL (Y+), Unity сама сконвертирует |
| `<имя>_emission.png` | Окна, огни, руны, прожилки; фон — чёрный |

Три слота материала (имена точно такие, код находит их по именам):
1. `Hull` — корпус (с текстурами выше);
2. `Accent` — **полосы цвета владельца**, плоский белый/серый материал: код красит его цветом империи и подсвечивает при выборе. Площадь — 8–15 % корпуса, **геометрией отдельных полос/панелей**, не текстурой;
3. `Glow` — двигатели, окна, свечение (код управляет яркостью).

Для `terraan` и `iridia` допустимо, чтобы `Accent` были светящимися прожилками/рунами, а не полосами.

### 4.4 Служебные объекты (Empty) — нужны для кода
| Имя | Назначение |
|---|---|
| `Nozzle_01…N` | Маршевые сопла (позиция + ось: тяга по −Z). У `iridia`/`nol` — центры энергетических колец |
| `Retro_01…N` | Тормозные сопла (струя вперёд +Z), 2–4 шт. малых |
| `Blink_01` | Мигающий навигационный огонь (небольшой меш с материалом `Blink`) |
| `Work_01…N` | Точки излучения строителя: где вспыхивают лучи/дроны (только строитель, 2–4 шт.) |
| `Scan_01` | Точка, откуда идёт луч/импульс скана (только научное) |
| `Anim_*` | Подвижные части (см. 4.5) |

### 4.5 Анимация (простая, по ключам в Blender)
- Научное: непрерывное вращение колец/антенн `Anim_Ring_*` (360° за 12–20 с, Linear, Loop); тарелка/лепестки раскрываются `Anim_Dish_Open` (кадры 0–60).
- Строительное: манипуляторы `Anim_Arm_*` — цикл «работы» (кадры 0–120, Loop) и поза покоя (кадр 0).
- Экспорт: анимации отдельными Action с именами `idle`, `work`/`scan`.

## 5. Требования к качеству «как в Stellaris»
1. **Три уровня детали**: крупные формы (читаются с карты) → средние (панели, конструкции, стыковки) → мелкие (клёпки, трубы, люки, маркировка). Без «гладких пластилиновых» поверхностей.
2. Запечённый износ: AO, лёгкие царапины и потёртости на кромках, тёмные подтёки у сопел, различный roughness между панелями.
3. Масштабные ориентиры: иллюминаторы, люки, мелкие антенны, лестницы — по ним должен читаться размер.
4. Читаемость на карте: на сером фоне 40×40 px корабль остаётся узнаваем; обязательно проверять **рендером сверху в 64 px**.
5. У каждой империи — **не перекрашенный** вариант: формы и пропорции действительно разные (не один корпус с разными цветами).
6. Единая цветовая схема внутри империи; насыщенные цвета — только акценты и эмиссия.
7. Никаких логотипов, текстов и узнаваемых надписей реальных брендов. Допустимы вымышленные знаки империи (эмблемы есть в игре: `Assets/Scripts/Rendering/FactionEmblems.cs`).

## 6. Сдача
Папка на каждую империю: `Assets/Resources/Models/Ships/<ключ>/`

```
<ключ>_science.fbx    <ключ>_construction.fbx
<ключ>_science_albedo.png / _ms.png / _normal.png / _emission.png
<ключ>_construction_albedo.png / _ms.png / _normal.png / _emission.png
```

Плюс вне репозитория:
- `.blend` с исходниками (слои/коллекции по LOD, нетронутые модификаторы там, где возможно);
- превью: 3 рендера на корабль — сверху (64 px и 512 px), 3/4, сбоку; общий лист «все 6 империй» для сравнения силуэтов;
- список материалов и использованных референсов/текстурных паков с лицензиями (без стоков с запретом на коммерческое использование).

## 7. Этапы и приёмка

| Этап | Результат | Приёмка |
|---|---|---|
| 1. Блок-аут | Серые модели 12 кораблей, силуэты, пропорции | Лист силуэтов 64 px: все 12 различимы, парами «строитель/учёный» одной империи — одно семейство |
| 2. Хай-детейл | Полная геометрия, LOD, служебные Empty | Бюджет трис, оси +Z/+Y, имена слотов и Empty по п. 4 |
| 3. Текстуры | Albedo/MS/Normal/Emission, ливреи | Просмотр в Unity URP/Lit при освещении карты; акцент-полосы красятся |
| 4. Анимация и экспорт | FBX, Action, превью, пакет для Unity | Модель встаёт в `Resources/Models/Ships/...` и без доработок попадает в игру |

Приёмку на каждом этапе делает заказчик по листу 64 px и скриншотам из игры. После этапа 4 код подключения (по образцу `Mars3Model.cs`) делается на стороне проекта.

## 8. Чего не делать
- Не использовать чужие модели и ассеты без явной лицензии на коммерческое использование.
- Не делать корпус полупрозрачным, не использовать шейдеры вне URP/Lit.
- Не «срезать» на одинаковых деталях между империями: узнаваемость по силуэту важнее детализации.
