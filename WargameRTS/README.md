# WargameRTS

Тактическая RTS в реальном времени в духе Wargame / Broken Arrow на Unity 6 (URP).

## Быстрый старт

1. Скачай ветку (GitHub Desktop или **Code → Download ZIP**).
2. Unity Hub → **Add → Add project from disk** → папка **`WargameRTS`**
   (не корень репозитория).
3. Открой в Unity **6000.6.3f1** → откроется сцена `MainMenu` → **Play**.
   (Если сцена не открылась — меню **WargameRTS → Play (Main Menu)**.)
4. В меню выбери **Бой с ИИ** или **Песочница** (спавн любой техники за любую
   сторону, управление временем, бессмертие — для тестов).

Управление — F1 в игре или таблица в гайде.
