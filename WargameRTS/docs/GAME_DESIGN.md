# WargameRTS — дизайн-документ (черновик)

Рабочее название: **WargameRTS** (финальное придумаем позже). Вдохновение —
серия **Wargame** (Eugen Systems) и **Broken Arrow** (Steel Balalaika).
Делаем свою игру с похожим геймплеем: механики копировать можно, а названия,
модели, звуки и тексты оригиналов — нельзя, только свои или лицензированные
ассеты.

## Суть

Тактическая RTS в реальном времени без базостроения. Игрок заранее собирает
**колоду** из реальных образцов современной техники, на карте получает
**очки командования** и вызывает подкрепления с края карты. Победа — за счёт
захвата и удержания **секторов** и уничтожения противника.

## Ключевые механики

| Механика | Что значит для нас |
|---|---|
| Колода (deck) | Перед боем выбираем карточки юнитов: категория (разведка, пехота, танки, поддержка, артиллерия, ПВО, вертолёты, авиация), количество, ветеранство |
| Очки и подкрепления | Очки копятся со временем и за сектора; юнит покупается и приезжает с края карты |
| Фаза развёртывания | В начале боя расставляем юниты в своей зоне до старта |
| Секторы / командиры | Сектор захватывается командирской машиной; даёт доход очков |
| Линия видимости и туман | Юнит видит только по LOS, лес/дома блокируют обзор; разведка видит дальше, «оптика» и «скрытность» |
| Дальности и точность | Каждое оружие: дальность, точность в движении/стоя, скорострельность, боезапас |
| Броня | Фронт/борт/корма/верх; кинетическое (АП) и кумулятивное (HEAT) оружие |
| Мораль и подавление | Обстрел копит подавление → точность падает → юнит паникует/отступает |
| Местность | Леса, здания — укрытие пехоте; дороги — скорость технике |
| Логистика | Топливо и боеприпасы; машины снабжения пополняют |
| Транспорт | Пехота ездит в БТР/БМП/вертолётах, высаживается по приказу |
| Артиллерия и авиация | Удары по точке, контрбатарейная борьба; самолёты заходят с края, ПВО их сбивает |
| Дым | Ставит завесу, блокирует LOS |
| Ветеранство | Опыт повышает точность и стойкость |

## План разработки (вехи)

Каждая веха — играбельный результат, который можно проверить в Unity.

- **M0. Подготовка** — проект, Git, LFS, CLAUDE.md, структура папок, asmdef. *(этот гайд)*
- **M1. Песочница** — тестовая карта (Terrain), RTS-камера, юнит-куб, выделение
  ЛКМ/рамкой, движение по ПКМ через NavMesh, группы Ctrl+1..9.
- **M2. Базовый бой** — `UnitDefinition`/`WeaponDefinition` (ScriptableObject),
  HP, оружие с дальностью и точностью, автоатака, приказ атаки, смерть.
- **M3. Видимость** — линия видимости с учётом рельефа и леса, туман войны,
  разведка, отображение «последней известной позиции» врага.
- **M4. Броня и пехота** — броня по сторонам, АП/HEAT, пехота, здания и леса
  как укрытия, транспорт с посадкой/высадкой.
- **M5. Мораль** — подавление, паника, отступление, ветеранство.
- **M6. Экономика матча** — очки, секторы, командиры, вызов подкреплений,
  фаза развёртывания, условия победы.
- **M7. Колоды** — редактор колоды, карточки юнитов, UI покупки.
- **M8. Противник** — ИИ: захват секторов, атака/оборона, покупка юнитов.
- **M9. Поддержка** — артиллерия, ПВО, вертолёты, самолёты, дым, снабжение.
- **M10. Контент и полировка** — модели, эффекты, звук, меню, настройки.
- **M11. Мультиплеер** — решить заранее (до M2!): детерминированный lockstep
  или серверная модель (Netcode for GameObjects / Entities). От этого зависит,
  как писать симуляцию.

## Открытые вопросы

- Сеттинг: реальные страны (как в оригиналах) или вымышленные фракции?
- Масштаб: сколько юнитов на игрока одновременно (сотни → вероятно DOTS/ECS
  для симуляции)?
- Мультиплеер на старте или только одиночная игра против ИИ?
- Масштаб карт (Wargame — до ~10×10 км) и камера (насколько далеко отдаляется).
