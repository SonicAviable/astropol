# Системные требования Astropolity

Предварительные: оценены по настройкам проекта (Unity 6, URP, Windows x64, Direct3D 11/12, HDR, SSAO,
тени до 4096, сглаживание до MSAA ×4, масштаб рендера 50–100% и AMD FSR 1.0), а не замерены на железе.
Перед публикацией стоит прогнать сборку на ПК уровня «минимальных» и «рекомендуемых».
Картинка: `VKPlay/system_requirements_ru.png` (пересобрать: `python3 Tools/sysreq/make.py`).

| | Минимальные | Рекомендуемые |
|---|---|---|
| Рассчитано на | 1080p, пресет «Низкое», 30+ кадров/с | 1080p, пресет «Высокое», 60 кадров/с |
| ОС | Windows 10 64-бит (21H2 и новее) | Windows 10 / 11 64-бит |
| Процессор | Intel Core i5-4460 / AMD Ryzen 3 1200 (4 ядра, 3,0 ГГц) | Intel Core i5-9600K / AMD Ryzen 5 3600 (6 ядер) |
| Оперативная память | 8 ГБ | 16 ГБ |
| Видеокарта | GeForce GTX 960 / Radeon R9 380 / Intel Iris Xe, 2 ГБ | GeForce GTX 1660 Super / Radeon RX 5600 XT, 6 ГБ |
| DirectX | 11 | 11 (поддерживается 12) |
| Место на диске | 6 ГБ | 6 ГБ на SSD |

Почему так:
- **Процессор** — главное для 4X: ИИ шести империй, экономика и пути флотов к поздней игре нагружают ЦП
  сильнее, чем графика; 6 ядер — запас для больших галактик.
- **Видеокарта** — карта галактики, 3D-планеты и корабли, HDR, SSAO, интерфейс «жидкое стекло», частицы
  в карточном бою (отдельная камера в текстуру). На слабых GPU выручают пресет «Низкое» и FSR 1.0.
- **Память** — арт, модели, записи звуков и видеоролики фракций в памяти; 8 ГБ хватает на средних
  галактиках, 16 ГБ — с запасом.
- **Диск** — собранная игра около 2–3 ГБ, остальное — сохранения, кэш шейдеров и обновления.

Как игра нагружает процессор и видеокарту (для игроков): `Docs/perf_threads_ru.png`
(пересобрать: `python3 Tools/perfchart/make.py`).
